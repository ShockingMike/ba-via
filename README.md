# Ba Vía: app tập gym cho nhóm bạn

**Trang theo dõi tiến độ:** https://shockingmike.github.io/ba-via/

- `TRACKING.md`: nguồn sự thật duy nhất về tiến độ (96 màn hình, lộ trình, quyết định). Sửa file này, đẩy lên là trang tự cập nhật.
- `CLAUDE.md`: hướng dẫn và các quyết định đã chốt cho mọi phiên Claude.
- `research/`: nghiên cứu luật tập, thư viện 90 bài tập, mẫu UX.
- `design/`: thế giới Ba Vía, nhân vật, tủ đồ, kế hoạch màn hình (`08-screen-plan.md`, `screens.json`).
